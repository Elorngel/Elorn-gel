Signature mail Bontin

Pour la boîte contact@bontin.fr dans l'app Mail (Mac et iPhone).

1. Ordinateur (Mail sur Mac)

Version du 27/11/2026 : la signature est seule dans le fichier signature-mail-seule.html (dans le même dossier). On la copie d'un coup avec Cmd + A : plus de cadre de couleur vide au-dessus, dans lequel on écrivait avec l'ancienne version.

  1. Ouvrez signature-mail-seule.html dans Safari (clic droit → Ouvrir avec → Safari).
  2. Cmd + A (tout sélectionner) puis Cmd + C (copier).
  3. Dans Mail : menu Mail → Réglages… → Signatures, compte contact@bontin.fr, signature Bontin.
  4. Cliquez dans la zone de droite, Cmd + A puis touche Effacer (on vide l'ancienne signature), puis Cmd + V.
  5. Décochez « Toujours utiliser ma police par défaut ». Fermez la fenêtre.

Écrire avec la police Bontin (Public Sans)

  1. Installez la police : fonts.google.com/specimen/Public+Sans → « Get font » → « Download all » → ouvrez le fichier .zip téléchargé → dossier static → sélectionnez tous les fichiers PublicSans-…ttf → double-clic → Installer.
  2. Mail → Réglages… → Polices et couleurs → « Police des messages » → Sélectionner… → Public Sans, taille 14.
  3. Fermez et rouvrez Mail.

Les destinataires qui n'ont pas Public Sans sur leur appareil voient vos messages dans leur police habituelle (Helvetica ou Arial) : c'est normal, la mise en page reste propre.

2. iPhone (app Mail)

Sur l'iPhone, Mail garde mal la mise en forme : on met une version texte, propre et lisible.
