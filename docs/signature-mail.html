  1. Ouvrez ce fichier dans Safari (il est déjà ouvert si vous lisez ceci dans Safari).
  2. Sélectionnez la signature ci-dessus avec la souris : du logo jusqu'à « Instagram ». Puis Cmd + C.
  3. Dans Mail : menu Mail → Réglages… → Signatures.
  4. À gauche, cliquez sur le compte contact@bontin.fr, puis sur le + en bas. Nommez-la « Bontin ».
  5. Dans la zone de droite, effacez le texte proposé et faites Cmd + V.
  6. Décochez « Toujours utiliser ma police par défaut » (sinon les couleurs et le gras disparaissent).
  7. En bas, menu « Choisir une signature » : sélectionnez Bontin pour ce compte. Fermez la fenêtre.

Vous voulez signer à votre nom ? Après le collage, remplacez « L'équipe Bontin » par « Romuald Elleouet – Responsable logistique » directement dans la zone de signature.
